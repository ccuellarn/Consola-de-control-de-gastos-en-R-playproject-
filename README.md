# Consola de control de gastos en R
Este es un pequeño proyecto personal para utilizar las herramientas técnicas y específicas de R, con el objetivo de crear una consola de gastos mensuales basándose en un presupuesto fijo mensual. 
<img width="1916" height="637" alt="Captura de pantalla 2026-10-07 111557" src="https://github.com/user-attachments/assets/100082be-5a1c-4b93-bb47-2ea169762a67" />

En dicha consola, se muestra el exceso y montos utilizados por categorías definiendo un presupuesto general. Se puede utilizar un ejemplo demo cargado por default en la consola o un archivo csv que cumpla con las columnas: Fecha (AAAA-MM-DD), descripción (etiqueta individual), categoría (etiqueta general) y monto (numérico, sin formato de dinero). Al inicio de la carga de datos se muestra un resumen sobre los gastos y porcentaje de presupuesto excedido por mes.

Además, se muestra en una animación la evolución de gastos mensuales por categorías de cada mes.
